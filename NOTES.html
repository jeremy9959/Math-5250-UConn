    Handoff notes: W07.3.qmd (SVD, norms, low-rank approximation)

    Working file: notes/Week7-8/W07.3.qmd. These notes record decisions and open items from a proofreading session (Nov 6–8, 2026) that aren’t visible from the file itself. The file is the source of truth; line numbers below are approximate.

    What was done

    • Proofread the whole file top to bottom; most typos, punctuation, and display-math formatting are fixed.
    • Converted to work over F = R or C throughout: SVD construction (X^X, unitary P, U, V; X = U Σ V^), operator norm and Frobenius sections (A^, \trace{A^*A}), low-rank overview and proofs (V^, v_i^*, unitary, |γ_i|^2).
    • Generalized the operator norm section to n×m matrices (supnorm(A) ≤ ||A|| ≤ sqrt(nm) supnorm(A), both constants sharp).
    • Macros added at top of file: \re (= \operatorname{Re}) and \trace{#1} (= \mathrm{trace}(#1), takes an argument). Note \Re was avoided because LaTeX already defines it.
    • Replaced the B = XY^T factorization lemma in the operator-norm low-rank proof with a rank–nullity argument: S = span(v_1, …, v_{k+1}) has dimension k+1, B(S) ⊂ col(B) has dimension ≤ k, so B|_S has a nonzero kernel vector.

    Open items

    1. Check the rank–nullity rewrite (~line 525). Make sure:
      • the γ_i are introduced (“Write w = Σ γ_i v_i; Σ|γ_i|^2 = 1”);
      • the reason dim B(S) ≤ k is stated (B(S) ⊂ column space of B) and the step is named as rank–nullity on B|_S;
      • “(k+1)-dimensional” is hyphenated;
      • every leftover reference to X, Y, Y^T, or “kernel of Y^T” is deleted.
    2. Line ~579: “Following the same line of argument as above” is misleading — the Frobenius proof uses the Weyl-type lemma, not the operator-norm argument. Probably just drop the phrase.
    3. Cauchy–Schwarz over C (line ~137). The cited proof (W05.1) is for real spaces only, but the complex case is used in the triangle inequality, ||A||^2 ≤ ||A^*A||, |<Av,w>| ≤ ||A|| ||v|| ||w||, and the Rayleigh quotient proposition. Cite or add a complex proof.
    4. Rows-as-coordinates remark (line ~23) is false for complex X (coordinates in an orthonormal basis involve conjugates). Not used by any proof. Either restrict to the real case or rephrase via columns: the j-th column of A = XP is Xp_j, and these are orthogonal with ||Xp_j||^2 = λ_j.
    5. Image compression (line ~93) uses V^T and “orthogonal”. This is correct as is (an image is a real matrix); optionally note that for real matrices V^* = V^T and unitary = orthogonal.

    Postponed: min-max / max-min characterization of singular values

    The “Min-max and Max-min characterization” section heading was removed for now. The plan, if it is added back:

    Statement: σ_k(A) = max over dim S = k of min over unit v in S of ||Av|| = min over dim T = m−k+1 of max over unit v in T of ||Av|| (equivalently via the Rayleigh quotient ||Av||2/||v||2 = <A^*Av,v>/||v||^2).

    Two lemmas, both already implicit in the operator-norm low-rank proof:

    • Lemma 1: for a unit w = Σ γ_i v_i, ||Aw||^2 = Σ σ_i^2 |γ_i|^2. So w ∈ span(v_1..v_j) ⇒ ||Aw|| ≥ σ_j, and w ∈ span(v_j..v_m) ⇒ ||Aw|| ≤ σ_j.
    • Lemma 2: if dim S + dim T > m in F^m, then S ∩ T ≠ 0 (or rank–nullity as in the rewrite above).

    Each direction of min-max is then ~3 lines. Suggested reorganization (preferred): Lemmas 1–2 → min-max theorem → operator-norm low-rank result as a 2-line corollary (ker B has dim ≥ m−k) → Weyl lemma → Frobenius result (unchanged). The k = 1 case recovers ||A|| = σ_1. Alternative: prove Courant–Fischer for a Hermitian M and apply it to M = A^*A, which also generalizes the self-adjoint Rayleigh-quotient proposition.
