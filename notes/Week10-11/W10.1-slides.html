Linear Functionals and the Dual Space

Math 5250 — Week 10

Overview

  • Linear functionals and the dual space \Hom(V,F).
  • Dual bases; \dim V=\dim\Hom(V,F) when V is finite-dimensional.
  • The double dual \Hom(\Hom(V,F),F) and the evaluation map \iota.
  • Dual linear maps \hat{L} and the transpose.
  • Duality for subspaces, quotients, and short exact sequences.

Notation. We write \hat{e}_i for dual basis vectors and \hat{L} for dual maps, to avoid confusion with adjoints.

Linear Functionals

Linear Functionals

Let F be a field and V a vector space over F. A linear functional on V is a linear map f:V\to F.

Examples (F=\R):

  1. V=\R^n, f((a_1,\ldots,a_n))=a_1.
  2. V=C[0,1] (continuous functions on [0,1]), f(v)=v(0.5).
  3. V=C[0,1], f(v)=\int_0^1 v(x)\,dx.
  4. V=\R^n with the dot product, w\in V fixed, f(v)=\langle w,v\rangle.

The Dual Space

Definition. The dual space \Hom(V,F) is the vector space of linear functionals on V, with (f_1+f_2)(v)=f_1(v)+f_2(v),\qquad (af_1)(v)=a\,f_1(v).

Proposition. If V is finite-dimensional, then so is \Hom(V,F), and \dim V=\dim\Hom(V,F).

Dual Bases

Let e_1,\ldots,e_n be a basis for V. A functional is determined by its values on a basis: f\Big(\sum a_ie_i\Big)=\sum a_if(e_i).

Define \hat{e}_1,\ldots,\hat{e}_n\in\Hom(V,F) by \hat{e}_i(e_j)=\delta_{ij} (extended linearly).

  • Spanning: f=\sum_j f(e_j)\,\hat{e}_j for every f\in\Hom(V,F).
  • Independence: if \sum_j a_j\hat{e}_j=0, evaluating at e_i gives a_i=0.

So \hat{e}_1,\ldots,\hat{e}_n is a basis for \Hom(V,F), the dual basis.

The Double Dual

The Evaluation Map

Proposition. For any vector space V over F, the map \iota:V\to\Hom(\Hom(V,F),F),\qquad \iota(v)(f)=f(v), is injective.

Proof. Choose a basis \{e_i\}_{i\in I} (Zorn’s lemma if needed). If v\neq 0, write v=\sum_{j\in J}a_je_j,\quad J\subset I \text{ finite},\ a_j\neq 0. For k\in J, define \hat{e}_k by \hat{e}_k(e_k)=1, \hat{e}_k(e_i)=0 for i\neq k. Then \hat{e}_k(v)=a_k\neq 0.

So every v\neq 0 has some f with f(v)\neq 0; hence \iota(v)=0 forces v=0.

Finite Dimensions

Corollary. If V is finite-dimensional, then \iota is an isomorphism.

Proof. \iota is an injective map between spaces of the same dimension: \dim V=\dim\Hom(V,F)=\dim\Hom(\Hom(V,F),F).

Note that \iota requires no choice of basis, unlike any isomorphism V\cong\Hom(V,F).

Infinite Dimensions

If V is infinite-dimensional, \iota is never an isomorphism.

  • Basis \{e_i\}_{i\in I}, I infinite; \hat{e}_i(e_j)=\delta_{ij}. The \hat{e}_i are independent.
  • Extend \{\hat{e}_i\} to a basis B of \Hom(V,F).
  • Define \varphi\in\Hom(\Hom(V,F),F) by \varphi(\hat{e}_i)=1 for all i\in I, and \varphi(g)=0 for the other g\in B.

If v=\sum_{j\in J}a_je_j with J finite, pick i\notin J. Then \varphi(\hat{e}_i)=1\neq 0=\hat{e}_i(v)=\iota(v)(\hat{e}_i), so \varphi\neq\iota(v).

Summary

Proposition. V is finite-dimensional if and only if \iota is an isomorphism.

Erdős–Kaplansky Theorem. If V is infinite-dimensional, then \dim\Hom(V,F)>\dim V in the sense of cardinality.

Duality and Linear Maps

The Dual Map

Let L:V\to W be linear and f\in\Hom(W,F). Then f\circ L:V\to F is a linear functional.

Proposition. The map \hat{L}:\Hom(W,F)\to\Hom(V,F),\qquad \hat{L}(f)=f\circ L, is linear. It is called the dual linear map to L.

Proof. For f,g\in\Hom(W,F), a\in F, and v\in V, ((af+g)\circ L)(v)=af(L(v))+g(L(v)), so \hat{L}(af+g)=a\hat{L}(f)+\hat{L}(g).

The Dual Map and the Transpose

Let V,W be finite-dimensional with bases A=\{a_1,\ldots,a_n\}, B=\{b_1,\ldots,b_m\}, and dual bases \hat{A}=\{\hat{a}_j\}, \hat{B}=\{\hat{b}_i\}.

Proposition. If X=[L]_A^B and Y=[\hat{L}]_{\hat{B}}^{\hat{A}}, then Y=X^{\top}.

Proof. We have L(a_j)=\sum_{k=1}^m x_{kj}b_k, so \hat{L}(\hat{b}_i)(a_j)=\hat{b}_i(L(a_j))=\hat{b}_i\Big(\sum_{k=1}^m x_{kj}b_k\Big)=x_{ij}. Since f=\sum_j f(a_j)\hat{a}_j for all f\in\Hom(V,F), \hat{L}(\hat{b}_i)=\sum_{j=1}^n x_{ij}\hat{a}_j=\sum_{j=1}^n y_{ji}\hat{a}_j, so y_{ji}=x_{ij}.

Subspaces, Quotients, and Exact Sequences

Restriction to a Subspace

Let V\subset W be a subspace with inclusion \alpha:V\to W. The dual map \hat{\alpha}:\Hom(W,F)\to\Hom(V,F) is restriction: it sends f to f|_V.

Lemma. \hat{\alpha} is surjective, and its kernel is the set of f:W\to F that vanish on V.

Proof.

  • \hat{\alpha}(f)=0 if and only if f(v)=0 for all v\in V.
  • Extend a basis of V to a basis of W. Extend a functional on V by zero on the new basis vectors; \hat{\alpha} maps it back to the original.

Functionals on a Quotient

Let \beta:W\to W/V be the quotient map. The dual map \hat{\beta}:\Hom(W/V,F)\to\Hom(W,F) is given by \hat{\beta}(f)(w)=(f\circ\beta)(w)=f(w+V).

Lemma. \hat{\beta} is injective, and its image is the set of functionals on W that vanish on V.

Proof.

  • If \hat{\beta}(f)=0, then f(w+V)=0 for all w, so f=0.
  • If w\in V, then w+V is the zero of W/V, so \hat{\beta}(f)(w)=0.
  • If f vanishes on V, the universal property gives \overline{f}:W/V\to F with \overline{f}(w+V)=f(w), and \hat{\beta}(\overline{f})=f.

Duality and Short Exact Sequences

Proposition. If 0\to A\xrightarrow{\ \alpha\ }B\xrightarrow{\ \beta\ }C\to 0 is a short exact sequence of vector spaces, then so is 0\to\Hom(C,F)\xrightarrow{\ \hat{\beta}\ }\Hom(B,F)\xrightarrow{\ \hat{\alpha}\ }\Hom(A,F)\to 0.

Proof. Identify A with \alpha(A)\subset B; then \beta induces B/\alpha(A)\cong C. The two lemmas give:

  • \hat{\alpha} is surjective,
  • \hat{\beta} is injective,
  • \ker\hat{\alpha}=\operatorname{im}\hat{\beta}=\{f\in\Hom(B,F): f|_{A}=0\}.
